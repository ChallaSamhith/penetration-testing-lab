# Home Cybersecurity Lab

A personal cybersecurity lab for learning and practicing network security, reconnaissance, vulnerability assessment, and penetration testing in a controlled virtual environment.

## Lab Setup

* **Kali Linux** — Security testing workstation
* **Metasploitable 2** — Intentionally vulnerable target
* **VMware** — Virtualization and lab networking
* **Nmap** — Network scanning and enumeration
* **Wireshark** — Network traffic analysis
* **Metasploit** — Vulnerability testing
* **Hydra** — Credential auditing

## Objectives

* Build an isolated cybersecurity lab
* Practice network reconnaissance and enumeration
* Analyze network traffic
* Understand and validate vulnerabilities
* Practice common penetration-testing techniques
* Document findings and lessons learned
